# Reproduction scope and provenance

## Numerical implementation

The Python numerical package is copied from the source snapshot used by the latest A323 and C546 experiment runners. The current V6 trainer depends on older shared trainers, decision layers, and model modules, so those modules remain in the package. `docs/source_provenance.json` records original checksums. Public runner edits concern portable paths, private identifier inputs, device selection, optional main-model-only aggregation, and figure presentation. Numerical model equations and losses are unchanged.

`configs/vascmtl.json` preserves the recorded input configuration. During execution, the `vascmtl` model selector applies the experiment's existing overrides, including `shared_only_mtl=True`, `soft_phenotype_adapters=False`, `isolate_cac_shared_gradient=False`, and `training_objective=joint_hps_mtl`. Reading an individual legacy field without those overrides can misidentify the effective model.

Each preparation stage records input hashes, private cohort membership, schema, fold assignments, and configuration hashes in a local protocol lock. Subsequent stages require the SHA256 of that lock. Patient-level files and full trained models remain local under `runs/`.

## Reference sources

The public 36-row metric table contains six metrics for each of six development/evaluation combinations. Its source CSV hashes are recorded in `source_provenance.json`. These files were read from archived results; they are not generated by this publication script or from synthetic inputs. Negative change R² values are retained.

The C546 full-refit manifest records NumPy 2.2.6, pandas 2.3.3, scikit-learn 1.6.1, PyTorch 2.9.1, and XGBoost 3.1.2. A complete historical Python/CUDA/driver lock was not available in that manifest. Different device/library versions can change training, selected epochs, and final estimates. The prepared-array contents, row order, original A354 outer folds, private exclusions, seeds, and training environment all matter for exact reproduction.

The A323 reference refit used encoded epoch value `73001000` and seed `3232026`; C546 used `69001000` and seed `35462026`. The joint trainer reads the first stage component as 73 or 69 joint epochs. The wrapper recomputes selection from newly trained OOF artifacts. It does not substitute archived reference predictions.

## Generated aggregate tables

After running the full workflow, the corresponding aggregate CSV files are:

| Development → evaluation | Path beneath `runs/` |
|---|---|
| A → A | `A323/results/A323_internal_fivefold_metrics_95ci.csv` |
| A → B | `A323/external_validation/B31_external_change_metrics_95ci.csv` |
| A → C | `A323/external_validation_c546/C546_external_change_metrics_95ci.csv` |
| C → C | `C546/results/C546_OOF_change_metrics_95ci.csv` |
| C → A | `C546/external_validation/A/C546_to_A323_change_metrics_95ci.csv` |
| C → B | `C546/external_validation/B/C546_to_B31_change_metrics_95ci.csv` |

Filter the A323 comparison output to `model == vascmtl`. Compare change R² (`tbr_r2_change`, `log_cac_r2_change`) rather than endpoint R². Legacy external A fields use `delta_log_cac_*`; the public table labels these `delta_log_tac_*`.

## Release preparation

The release was assembled from an explicit list of source code, configurations, documentation, and aggregate tables. No original dataset, patient-level output, fitted preprocessor, checkpoint, or credential is included. Packaging is not evidence of a fresh full experiment run; no full training or numerical reproduction was run for this upload.
